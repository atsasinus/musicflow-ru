# MusicFlow-RU

Russian-localized MusicFlow for Windows and Android. The project keeps the original app's features and GPL-3.0 license while translating its interface and user-facing messages into Russian.

**Documentation:** [English](README-EN.md) · [Русский](README-RU.md)

The Windows app uses a Flask server and the shared web interface in `index.html`. Android displays the same interface in a WebView and uses Chaquopy and Kotlin for platform features.

See the language-specific guides for Windows startup, EXE packaging, Android APK builds, and interface synchronization.

Original project: [captentv1/musicflow](https://github.com/captentv1/musicflow) · License: [GPL-3.0](LICENSE).
